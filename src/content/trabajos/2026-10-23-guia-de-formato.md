Este trabajo sirve de **muestra**: usa todos los elementos de formato que admite la web, para ver cómo queda cada uno. El primer párrafo es el que aparece como extracto en la portada y al compartir el enlace.

## Texto con estilo

Dentro de un párrafo se puede escribir en **negrita**, en *cursiva*, en ***negrita y cursiva a la vez*** o ~~tachar algo que ya no vale~~. También se puede marcar una palabra técnica como `código`.

Un enlace se escribe así: [la Real Academia Española](https://www.rae.es). En la versión impresa aparece la dirección entre paréntesis.

Para cortar una línea sin empezar un párrafo nuevo,  
se termina la línea con dos espacios.  
Es útil para poemas o direcciones.

## Títulos de distintos niveles

El título del trabajo es el más grande. Dentro del texto hay tres niveles más:

### Subtítulo de tercer nivel

Sirve para dividir un apartado en partes.

#### Subtítulo de cuarto nivel

Para divisiones todavía más pequeñas. Conviene no abusar de ellos.

## Listas

Una lista con viñetas:

- Introducción
- Desarrollo
  - Primera idea
  - Segunda idea
- Conclusión

Una lista numerada:

1. Leer el texto con atención.
2. Subrayar las ideas principales.
3. Escribir un resumen con palabras propias.

Una lista de tareas:

- [x] Elegir el tema
- [x] Buscar información
- [ ] Revisar la ortografía

## Notas al pie

Una afirmación puede llevar una nota al pie[^1] que se explica al final del trabajo.

[^1]: Las notas al pie se numeran solas y aparecen al final, con un enlace para volver al texto.
